# Travel YTT

Bu proje, Next.js kullanılarak geliştirilmiş bir seyahat uygulamasıdır. Kullanıcıların seyahat destinasyonlarını keşfetmelerine ve planlamalarına yardımcı olmayı amaçlar.


## Özellikler

*   **Destinasyon Keşfi:** Popüler ve ilgi çekici seyahat destinasyonlarını keşfedin.
*   **Seyahat Planlaması:** Seyahatlerinizi kolayca planlayın ve organize edin.
*   **Kullanıcı Dostu Arayüz:** Basit ve sezgisel bir kullanıcı deneyimi sunar.
