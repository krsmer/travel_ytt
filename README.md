# 🧳 Travel YTT

**Travel YTT** is a travel-focused web application built with **Next.js** and **Tailwind CSS**.  
It aims to help users discover exciting travel destinations and plan their trips with ease.

---

## ✨ Features

- 🌍 **Discover Destinations:** Explore popular and interesting travel locations.
- 🗓️ **Trip Planning:** Easily plan and organize your travels.
- 🧭 **User-Friendly Interface:** Simple, clean, and intuitive user experience.

---

## 🛠️ Tech Stack

- [**Next.js**](https://nextjs.org/) – React framework for building fast web apps  
- [**TypeScript**](https://www.typescriptlang.org/) – Strongly typed JavaScript  
- [**Tailwind CSS**](https://tailwindcss.com/) – Utility-first CSS framework for styling  
- [**JavaScript**](https://www.javascript.com/) – For additional logic and interactivity  

> 🧑‍💻 **Note:** This project currently includes only the frontend implementation. There is no backend or API integration at this stage.

---

## 📦 Installation

To run the project locally, follow these steps:

### 1. Clone the repository

```bash
git clone https://github.com/your-username/travel-ytt.git
cd travel-ytt
npm install
# or
yarn install
npm run dev
# or
yarn dev
```
